# پوشه‌ی فایل‌های دانلود

فایل‌های نصب و آپدیت باید داخل همین پوشه (`public/Download`) قرار بگیرند تا سایت آن‌ها را سرو کند.

## ساده‌ترین راه — آپلود از طریق سایت GitHub (بدون نیاز به نرم‌افزار)

1. وارد سایت **github.com** شوید و به مخزن سایت بروید
2. به مسیر `public` و سپس `Download` بروید
3. روی **Add file** و بعد **Upload files** کلیک کنید
4. فایل‌ها را بکشید و رها کنید (اسامی فایل‌ها را **دقیقاً** مثل قبل نگه دارید — حتی فاصله‌ها مهم هستند)
5. پایین صفحه روی **Commit changes** بزنید
6. یکی دو دقیقه صبر کنید تا Vercel دیپلوی کند — بعد دکمه‌های دانلود کار می‌کنند

## نکته‌ی مهم درباره‌ی اسم فایل‌ها

اسم هر فایل باید **دقیقاً** با آدرسش یکی باشد، مثلاً:
- `AnyDesk.exe`
- `TSOFT Setup.zip` (با فاصله)
- `TeamViewer.15.13.6_ TSOFT20.ir.exe` (با فاصله)
- `Foxit PDF Creator  Win 64.zip` (با دو فاصله)

اگر اسم فایل را عوض کنید، آدرسش در `src/data.ts` هم باید عوض شود.

## فایل‌های حجیم (بیش از ۱۰۰ مگابایت)

گیت‌هاب برای هر فایل سقف ۱۰۰ مگابایت دارد. فایل‌های بزرگ‌تر (مثل پارت‌های SQL Server اگر بزرگ باشند) را نمی‌شود این‌جا گذاشت. برای این فایل‌ها دو راه دارید:

- فایل را روی هاست یا فضای ابری دیگری آپلود کنید و آدرسش را در `src/data.ts` عوض کنید
- یا فایل را به چند پارت کوچک‌تر تقسیم کنید

## اگر هاست قدیمی هنوز زنده است

اگر فایل‌ها هنوز روی هاست قبلی هستند و آدرس مستقیمی برای آن هاست دارید (مثلاً IP سرور قدیمی)، لازم نیست فایل‌ها را جابه‌جا کنید — آدرس را به توسعه‌دهنده بدهید تا در `vercel.json` هدایت خودکار گذاشته شود.
