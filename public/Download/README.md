# پوشه‌ی دانلود

فایل‌های واقعی نرم‌افزارها را با **همین نام‌های دقیق** داخل همین پوشه (`public/Download`) قرار دهید و پروژه را push کنید.

سپس آدرس‌ها به‌صورت خودکار کار می‌کنند؛ مثلاً:

- `public/Download/AnyDesk.exe` ← `https://www.tsoft20.ir/Download/AnyDesk.exe`
- `public/Download/TSOFT Setup.zip` ← `https://www.tsoft20.ir/Download/TSOFT Setup.zip`

## نکات مهم

1. نام فایل‌ها دقیقاً مثل لیست داخل `src/data.ts` باشد (حروف بزرگ و کوچک و فاصله‌ها مهم است).
2. فایل‌های حجیم (بیش از ۱۰۰ مگابایت) را در گیت‌هاب نگذارید؛ بهتر است آن‌ها را روی هاست یا فضای ابری دیگری آپلود کنید و آدرس‌شان را در `src/data.ts` عوض کنید.
3. بعد از push، یکی دو دقیقه صبر کنید تا Vercel دیپلوی کند؛ سپس لینک‌ها را تست کنید.
